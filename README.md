# Odoo Technical Training - Server Framework 101

Welcome to the Odoo Server Framework 101 workshop repository!

This repository contains the training code and step-by-step solutions for the official [Odoo Server Framework 101 Tutorial](https://www.odoo.com/documentation/master/developer/tutorials/server_framework_101.html).

## Repository Overview

- `main`: Clean starting branch for students to write their code.
- `solution`: Step-by-step reference solutions for each chapter.
- Tags: `chapter-1`, `chapter-2`, ..., `chapter-14` tag each chapter's commit on the `solution` branch.

## How to use this repository

1. Start on the `main` branch:
   ```bash
   git checkout main
   ```

2. As you progress through the tutorial chapters, you can either implement the changes yourself or inspect the solution.

3. To catch up or check your work against the official solution for any chapter, cherry-pick the chapter tag:
   ```bash
   git cherry-pick chapter-1
   git cherry-pick chapter-2
   # and so on...
   ```
